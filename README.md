## Selected projects

### Automated attendance application

Built a mobile attendance system that uses timetables and building geofences to record attendance automatically.

- Developed a Flutter mobile client with a Python FastAPI backend and SQLite database.
- Implemented clock-in rules, a five-minute exit grace period and automatic clock-out.
- Calculated attendance from the time spent in each session.
- Added timetable status indicators and an attendance event log.

**Tools:** Python, FastAPI, SQLite, Flutter, Dart and Geolocator.

### Credit card fraud detection

Compared machine learning approaches for detecting fraud in a highly imbalanced dataset of 284,807 transactions.

- Evaluated random forest and logistic regression models using stratified cross-validation.
- Applied undersampling within training folds while preserving the original class balance for testing.
- Assessed recall and the area under the receiver operating characteristic curve (ROC-AUC).
- Explored error costs and model behaviour across transaction amount bands.

**Tools:** Python, scikit-learn and machine learning evaluation.

### Intelligent device discovery and semantic data integration

Built an Internet of Things (IoT) prototype that discovers sensor messages and converts them into a consistent data format.

- Used MQTT wildcard subscriptions to discover incoming device messages.
- Standardised sensor type, value, unit, device and timestamp fields.
- Connected a Python publisher, Mosquitto, Node-RED and InfluxDB.
- Evaluated message latency and throughput.

**Tools:** Python, MQTT, Mosquitto, Node-RED and InfluxDB.
